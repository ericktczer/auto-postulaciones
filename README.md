# auto-postulaciones

Automatizador de postulaciones de trabajo para México (LinkedIn, Indeed, Computrabajo, OCC).

- `docs/ANALISIS_REPOS.md`: análisis de los dos repos de referencia.
- `docs/PROMPT_AUTOMATIZADOR.md`: prompt para construir el sistema con Claude Code.

Aviso: estos portales restringen la automatización en sus términos de uso. Empieza siempre en `dry_run`. Las claves van solo en variables de entorno.
